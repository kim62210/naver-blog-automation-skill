## Image Generation Guide

### 🚨 IMPORTANT: Each Image Section Must Be 1000+ Characters

Ensure each image section above contains:
- Korean Description: 100-150자 (이미지가 무엇을 표현하는지 상세히)
- AI Generation Prompt: 400-500자 (모든 시각 요소, 텍스트, 색상 상세)
- Style Guide: 100-150자 (HEX 색상 코드, mood 키워드)
- Watermark Config: 150-200자 (6개 필드 모두)

### AI Image Generation (Gemini API Auto)
Images are automatically generated via Gemini API.
The pipeline parses this file and generates images with the specified prompts.

### Checklist Before Generation
- [ ] All Korean text in quotes with exact characters
- [ ] Color codes in HEX format (e.g., #1a365d)
- [ ] Position specified for text elements
- [ ] 1:1 (500x500) ratio for thumbnail, appropriate ratios for others
- [ ] Thumbnail prompt includes layout specs (thumbnail_layout.svg 비례)
- [ ] Thumbnail prompt includes font style (Gmarket Sans Bold / SB Aggro Bold)
- [ ] All 6 watermark config fields included per image
- [ ] Each section reaches 1000+ characters total

### Image Optimization
- Recommended blog upload width: 800px
- File format: PNG (for text clarity)
- File size: 1MB or less recommended
