## 7-2. 원본.txt 작성 원칙

### (1) 순수 텍스트로만 작성
- HTML 태그 금지 (`<h2>`, `<p>`, `<br>` 등)
- 마크다운 서식 금지 (`**굵게**`, `__밑줄__` 등)
- 문단은 **빈 줄**로 구분

### (2) [괄호]는 “가이드/지시”로만 사용
원본.txt에는 “최종 출력에서 어떻게 렌더링할지”를 [괄호]로 명시합니다.

#### 렌더 태그 (텍스트는 남고, 태그만 제거됨)
- `[제목] 제목 텍스트`
- `[중제목] 중제목 텍스트`
- `[소제목] 소제목 텍스트`
- `[인용] "인용문 텍스트"`
- `[폰트:24px bold] 이 문장은 24px 굵게 렌더링`
- `[강조:Bold] 강조할 문장`

#### 렌더 제외 메모 (최종 출력에 포함되지 않음)
- `[[여기서 표 넣을지 판단]]`
- `[[이 단락은 30~50자 늘리기]]`

#### 이미지 위치 플레이스홀더 (글자수 카운트 제외)
- `[이미지 1 삽입 - 썸네일]`
- `[이미지 2 삽입]`

> ✅ 원칙: **최종 블로그에 보일 문장/제목/인용은 반드시 [태그] 뒤에 실제 텍스트로 써야 합니다.**

## 7-3. 글자수 규칙 (🚨 MANDATORY)

- 목표: 1900자 내외
- 허용 범위: **1850~1950자**

### 포함/제외 기준 (원본.txt 기준)
- **포함**: 제목/중제목/소제목/인용/본문의 실제 텍스트
- **제외**: `[이미지 N 삽입...]` 플레이스홀더, `[[...]]` 메모, `[태그]` 자체 문자열

### Python 글자수 검증 (원본.txt)
```python
from pathlib import Path
from scripts.validator import validate_draft_char_count

draft_text = Path(project_path / "원본.txt").read_text(encoding="utf-8")
result = validate_draft_char_count(draft_text)
print(result.message)  # ✅ Valid / ⚠️ Over / ⚠️ Under
```

## 7-5. 원본.txt 예시 (축약)

```
[제목] 2026 육아휴직 급여, 부모가 꼭 알아야 할 3가지

[이미지 1 삽입 - 썸네일]

[소제목] 첫 번째 변화: 급여 상한과 지급 구조
[강조:Bold] 결론부터 말하면, 실수령이 달라집니다.
...

[이미지 2 삽입]

[중제목] 신청 전에 꼭 확인할 체크리스트

[폰트:19px bold] ② 회사 내 규정/대체인력
...
```
