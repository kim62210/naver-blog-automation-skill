## 7-2. 원본.txt 작성 원칙

### (1) 순수 텍스트로만 작성
- HTML 태그 금지 (`<h2>`, `<p>`, `<br>` 등)
- 마크다운 서식 금지 (`**굵게**`, `__밑줄__` 등)
- 문단은 **빈 줄**로 구분

### (2) [괄호]는 “가이드/지시”로만 사용
원본.txt에는 “최종 출력에서 어떻게 렌더링할지”를 [괄호]로 명시합니다.

#### 렌더 태그 (텍스트는 남고, 태그만 제거됨)
- `[제목] 제목 텍스트`
- `[중제목] 중제목 텍스트`
- `[소제목] 소제목 텍스트`
- `[인용] "인용문 텍스트"`
- `[폰트:24px bold] 이 문장은 24px 굵게 렌더링`
- `[강조:Bold] 강조할 문장`

#### 렌더 제외 메모 (최종 출력에 포함되지 않음)
- `[[여기서 표 넣을지 판단]]`
- `[[이 단락은 30~50자 늘리기]]`

#### 이미지 위치 플레이스홀더 (글자수 카운트 제외)
- `[이미지 1 삽입 - 썸네일]`
- `[이미지 2 삽입]`

> ✅ 원칙: **최종 블로그에 보일 문장/제목/인용은 반드시 [태그] 뒤에 실제 텍스트로 써야 합니다.**

## 7-3. 문체 가이드 (🚨 MANDATORY)

> 📖 전체 가이드: [네이버 블로그 문체 가이드](../네이버_블로그_문체_가이드.md)

아래는 원본.txt 작성 시 **반드시 적용해야 하는** 핵심 규칙입니다.

### (1) 톤 & 종결어미

| 종결어미 | 비율 | 예시 |
|---------|------|------|
| ~합니다/습니다 | **70%** | "매우 인기가 많습니다", "불가능합니다" |
| ~이다/~다 (서술형) | **20%** | "자산 기준이다", "아직 멀었다" |
| ~죠/~요 (구어체) | **10%** | "뻔하죠", "~거든요" |

- **1인칭 적극 사용**: "저도", "저는", "제가 해봐서 잘 압니다", "제 경험으로는"
- **독자 호소 표현**: "여러분", "~하시는 분들", "~하시겠죠?"
- **감정 표현 병행**: 데이터 제시 후 감정 코멘트 추가 (객관→감정 리듬)

### (2) 문장/문단 구조

- **문장 길이**: 20~40자 (최대 50자)
- **리듬**: short → long → short 반복
  - 짧은 문장(15~25자) → 긴 설명(35~45자) → 짧은 요약(15~25자)
- **문단**: 1~3문장/문단, 줄바꿈 적극 활용
- **질문+즉답 구조**: "뭐가 다르냐? 바로 수수료입니다."

| 연결어 기능 | 자주 쓰이는 표현 |
|------------|----------------|
| 역접 | 하지만, 그런데, 그래도 |
| 순접 | 그래서, 따라서, 그러니 |
| 인과 | 결국, ~때문이다, 덕분에 |
| 추가 | 또한, 게다가, 심지어 |
| 전환 | 한편, 그런데 |

### (3) 도입부 패턴

| 유형 | 비율 | 템플릿 |
|------|------|--------|
| 공감형 | **40%** | "{현재 트렌드}하면서 {독자 상황}하신 분들이 많을 것입니다." |
| 결론 선제시형 | **25%** | "결론부터 말하면 {핵심 결론}하는 게 유리하다." |
| 질문 유도형 | **20%** | "도대체 왜 {상황}하는 걸까요?" |
| 통계/팩트형 | **15%** | "{핵심 수치/데이터}. 이 숫자가 의미하는 바는..." |

### (4) 마무리 패턴

| 유형 | 비율 | 템플릿 |
|------|------|--------|
| 권유/CTA형 | **45%** | "~해 보시기 바랍니다" |
| 질문형 | **25%** | "여러분의 ~은 무엇인가요?" |
| 요약/정리형 | **20%** | "정리하면 {핵심 3줄 요약}" |
| 개인 소감형 | **10%** | "제 꿈은 ~입니다" |

### (5) 강조/리스트

- **볼드**: 전체 텍스트의 **5~10%**만 볼드 처리 (핵심 결론/경고에 집중)
- **리스트**: 번호 리스트 선호 ("1. ...", "2. ...", "3. ...")
- **이모지**: 본문 내 최소화, CTA(공감/댓글 유도)에만 사용

### (6) 숫자 표기법

| 유형 | 표기 방식 | 예시 |
|------|----------|------|
| 큰 금액 | 한글+아라비아 혼합 | "3억 4천만원", "600만 원" |
| 작은 금액 | 아라비아 숫자 | "1,875원", "49만 5천원" |
| 퍼센트 | 아라비아 + % | "23.9%", "0.2%", "50% 이상" |
| 순위/개수 | 아라비아 숫자 | "TOP 5", "3가지", "10명 중 7명" |
| 연도/날짜 | 아라비아 숫자 | "2026년 1월", "2월 28일" |

- 목표: 1900자 내외
- 허용 범위: **1850~1950자**

### 포함/제외 기준 (원본.txt 기준)
- **포함**: 제목/중제목/소제목/인용/본문의 실제 텍스트
- **제외**: `[이미지 N 삽입...]` 플레이스홀더, `[[...]]` 메모, `[태그]` 자체 문자열

## 7-6. 원본.txt 예시 (축약)

```
[제목] 2026 육아휴직 급여, 부모가 꼭 알아야 할 3가지

[이미지 1 삽입 - 썸네일]

[중제목] 왜 2026년 개정이 중요한가
요즘 육아휴직 급여가 달라진다는 소식에 관심 갖고 계신 분들이 많을 것입니다.
저도 아이를 키우면서 가장 먼저 확인했던 게 바로 급여 구조였습니다.
핵심은 '시간'이 아니라 '돈'이었습니다.
[[여기서 최근 제도 변경의 배경을 1~2문장 더 보강]]

[인용] "급여 구조가 바뀌면, 휴직을 선택하는 사람이 늘어날 수밖에 없다"

[소제목] 첫 번째 변화: 급여 상한과 지급 구조
[강조:Bold] 결론부터 말하면, 실수령이 달라집니다.
기존에는 월 150만 원이 상한이었습니다.
하지만 2026년부터는 최대 250만 원까지 올랐습니다.
얼마나 차이가 나냐? 월급 300만 원 기준으로 약 50만 원 더 받습니다.
...

[이미지 2 삽입]

[중제목] 신청 전에 꼭 확인할 체크리스트
[폰트:19px bold] ① 고용보험 가입기간
[폰트:19px bold] ② 회사 내 규정/대체인력
...

[중제목] 마무리
육아휴직을 고민 중이시라면, 오늘 정리한 3가지만 꼭 챙겨 보시기 바랍니다.
여러분은 어떤 부분이 가장 궁금하셨나요?
```
